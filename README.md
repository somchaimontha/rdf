## ภาษาไทยและภาษาอังกฤษ (i18n)

รองรับการเลือกภาษาไทยและอังกฤษผ่านปุ่มสลับภาษา และจดจำภาษาที่เลือกไว้ในเบราว์เซอร์
คำแปลส่วนกลางอยู่ใน `assets/js/i18n.js` ส่วนหน้าเว็บอัปเดตข้อความ ตาราง และกราฟจากข้อมูลที่โหลดไว้
การสลับภาษาต้องรักษาค่าฟอร์ม ตัวกรอง และตัวเลือกที่ยังไม่บันทึก

**ข้อกำหนดสำหรับงานใหม่:** ทุกการเพิ่มหรือแก้ไขข้อความและส่วนติดต่อผู้ใช้ต้องรองรับทั้งภาษาไทยและอังกฤษก่อน commit โดยปฏิบัติตาม [ข้อกำหนดของ repository](AGENTS.md)

- ข้อความหน้าจอ: ใช้ `data-t` กับข้อความที่ต้องการแปล
- Placeholder, tooltip และข้อความสำหรับเครื่องมืออ่านหน้าจอ: ใช้ `data-t-placeholder`, `data-t-title` และ `data-t-aria-label`
- เนื้อหาที่สร้างภายหลัง: รองรับการแปลอัตโนมัติเมื่อเพิ่มองค์ประกอบเข้า DOM
- รายงาน: รูปกราฟใช้ภาษารายงานที่เลือก โดยไม่เปลี่ยนภาษาหน้าจอที่บันทึกไว้

ดูรายละเอียดการพัฒนาและข้อจำกัดการทดสอบใน [คู่มือ i18n และการทดสอบ](tests/README.md)

## ตรวจสอบก่อน commit / push

รันจากโฟลเดอร์โครงการ (ทดสอบด้วย Node.js 24):

```sh
node --test tests/i18n.test.cjs
git diff --check
git diff --cached --check
```

สำหรับการทดสอบใน Chrome ให้เปิด Chrome ด้วยโปรไฟล์ทดสอบและ remote debugging ตามขั้นตอนใน
[คู่มือการทดสอบ](tests/README.md#validation) แล้วรัน:

```sh
node tests/i18n.browser.cjs 9222
```

ชุดทดสอบเบราว์เซอร์ใช้ข้อมูล API และไลบรารีภายนอกจำลอง ครอบคลุม 10 หน้า ทั้งภาษาไทยและอังกฤษ
ไม่ได้บันทึกข้อมูลไปยังระบบจริง และไม่ใช้แทนการตรวจรูปแบบ PDF หรือการเชื่อมต่อ Google Apps Script จริง

## เชื่อมต่อ Google Apps Script ด้วย clasp

- `Code.gs`: backend API และ `RDF_SPREADSHEET_ID` สำหรับชีตฐานข้อมูล
- `databasesetup.gs`: ฟังก์ชันตั้งค่าโครงสร้างฐานข้อมูลจากโปรเจกต์เดิม
- `appsscript.json`: manifest, runtime, timezone และ OAuth scopes
- `.clasp.json`: กำหนด Script ID ของโปรเจกต์ปลายทาง แยกจาก Spreadsheet ID
- `.claspignore`: จำกัดชุดอัปโหลดไว้ที่ไฟล์ backend สามไฟล์ข้างต้น

ตรวจรายชื่อไฟล์ก่อนอัปโหลดด้วย `clasp status` การใช้ `clasp push` อัปเดตโค้ดโปรเจกต์
แต่การเปลี่ยนเวอร์ชัน web app ที่เผยแพร่แล้วเป็นขั้นตอนแยกต่างหาก
ไม่ต้องรัน `setupDatabase()` เพื่ออัปเดตโค้ดหรือเชื่อมต่อโปรเจกต์เดิม

ไฟล์ backend ยังคงถูกยกเว้นจาก Git ตามการตั้งค่าเดิม ส่วน `.clasp.json` และ `.clasprc.json`
เป็นการตั้งค่าในเครื่อง ไม่รวมในชุด commit ของเว็บไซต์
